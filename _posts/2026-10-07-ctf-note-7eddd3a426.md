# 反编译

```c
int __fastcall main(int argc, const char **argv, const char **envp)
{
  init(argc, argv, envp);
  vuln();
  return 0;
}

ssize_t vuln()
{
  _BYTE buf[512]; // [rsp+0h] [rbp-200h] BYREF

  puts("How many bytes do you want to write?");
  __isoc99_scanf("%d", &num);
  if ( (unsigned int)num > 0x200 )
  {
    puts("Too many");
    exit(0);
  }
  puts("I can give you one more");
  return read(0, buf, num + 1);
}
```

# 思路

给了 1 bytes 的溢出，只能覆盖返回的 rbp ，程序段给了 `system()` `/bin/sh` `pop rdi; ret`。

所以只要能获得一次执行，就能直接通过 rop 去 get shell。

只给了 1 bytes 的控制范围，且只能控制rbp，考虑栈迁移。这里能实现栈迁移，要注意`vuln()`函数返回后，会直接从 main 退出。所以程序的溢出逻辑结束后，就有一次双`leave; ret`来进行栈迁移，由于不能泄露栈地址，所以覆盖最低字节，与布置 rop 链的位置，要考虑栈地址的随机化，对其的低位偏移进行 1/16 爆破。
