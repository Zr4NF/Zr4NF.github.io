# 反编译
```c
int __fastcall main(int argc, const char **argv, const char **envp)
{
  init(argc, argv, envp);
  puts("If you open this elf,you are good at stack_overflow");
  puts("But I just want to give you 8 bytes");
  puts("Good game :)");
  return vuln();
}

ssize_t vuln()
{
  _BYTE buf[256]; // [rsp+0h] [rbp-100h] BYREF

  return read(0, buf, 0x110u);
}
```

只给了0x10的溢出。

# 思路
```asm
.text:00000000004011D9                 lea     rax, [rbp+buf]
.text:00000000004011E0                 mov     edx, 110h       ; nbytes
.text:00000000004011E5                 mov     rsi, rax        ; buf
.text:00000000004011E8                 mov     edi, 0          ; fd
.text:00000000004011ED                 call    _read
```
迁移中经典的gadget，通过这个进行栈迁移。

1. 通过如上段将栈劫持到bss段
2. 通过第二次写入，执行第一次rop，通过got表泄露libc，这里 `puts` 取`main`函数中的，泄露后通过`call vuln`，获取第三次写入
3. 通过第三次写入，注意这里的 rop 链的地址会因为`call`指令与上次不同，最好 dbg 接进去直接复制，执行rop，getshell
*tips：这里第三次选择执行`system(/bin/sh\0)`，该函数的栈帧非常大，调用该函数时，尽量劫持bss段偏下面的位置，不然容易crash*
