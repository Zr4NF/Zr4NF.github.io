# 逆向
一个在线人生模拟器。

main函数中有四个可进入函数：

```
buy_house()
supermarket()
work()
emergency_relief()
```

`main`中有一个day_end部分，在做错误选择或选择完后，会过一天，并且每三天会`-0.5 food`

`work()`函数中，可以通过算数获得钱，但每次只给3.0。

`supermarket()`中，可以购买十五，或卖掉食物。

`emergency_relief()`会在需要扣食物，但食物不足时触发，可以在这买食物度过一天。

vuln在`buy_house()`函数中，输入想购买的房子大小后，需要支付巨额的钱，之后可获得房子大小的写入缓冲区机会，只要房子够大，就可以随意溢出。

# 思路
最直接的，可以写刷分脚本，写脚本时，若不买food，只通过触发`emergency_relief()`，买食物，它会根据钱的多少来定价，钱越多，越贵

同时`supermarket()`函数有购买食物上线，基本锁死了刷分脚本

那回到vnlu处来：

发现此处只需要money为`NAN`就能绕道过if判断。


之后注意到题目的提示，发现money和food全局变量都是浮点数，同时注意到`emergency_relief()`中以下代码：

```
  wana_food = money / price;
  v4 = money;
  money = 0.0;
  food = wana_food + food;
```

也就是说，只要让money为0，就能获得`food == NAN`
